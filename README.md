# CorreoPlus V1.0.3 — Cabecera de mensajes plegable

Basado en V1.0.2. Una sola cuenta.

- Asunto y remitente en una cabecera compacta.
- Toca la cabecera o la flecha para mostrar/ocultar Fecha, De, Para, CC y CCO (cuando el servidor lo proporciona).
- El resumen de destinatarios se abrevia visualmente, sin eliminar direcciones de la sección desplegada.
- Barra inferior fija con favorito, archivar, eliminar, responder y reenviar.
- Adjuntos y lectura HTML existentes conservados.

Compilar con GitHub Actions. La compilación y el funcionamiento en Android no se han verificado localmente.


## V1.0.4
- Destinatarios en filas individuales, con nombre y dirección por separado, agrupados por De, Para, CC y CCO cuando existe.
- Adjuntos en sección desplegable, inicialmente cerrada, con apertura y guardado al expandir.
- Requiere compilación y pruebas en Android.
