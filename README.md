# CorreoPlus V0.8 Beta — Adjuntos

Basado en V0.7.2, una sola cuenta.

## Nuevo
- Leer lista de adjuntos del mensaje IMAP por UID y descargarlos mediante el selector de archivos de Android.
- Adjuntar documentos desde el selector de Android y enviarlos por SMTP en un mensaje MIME multipart.
- Límite de 25 MB por adjunto para evitar agotar la memoria.

## Pendiente
- Notificaciones y sincronización en segundo plano.
- Prueba de compilación GitHub Actions y pruebas reales en el móvil.

## Instalación
Extrae el ZIP y copia todos los archivos al repositorio con MGit; commit y push. Comprueba el workflow build-apk y descarga el APK.
